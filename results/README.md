# Evaluation artifacts

- `measure_summary.csv`: descriptive statistics for sub-pixel width, height, rectangularity, and edge RMS.
- `defect_metrics.json`: pixel-, component-, and image-level results for the two product families.
- `unknown_product_metrics.json`: identity, coverage, review-rate, and end-to-end inspection metrics for confidence-aware routing.

These files are retained as compact evidence of the reported course-project run; raw images and per-image predictions are excluded.
